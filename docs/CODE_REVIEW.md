## 메모

- (d) 고정 출전 — 확인한 경로
  - 고정 선수가 2군·부상자 명단·방출·트레이드: `forceStarter` 가 null 을 돌려 아무 일도 없다. 만료 때 `unfixMut` 은 선발 칸에 그 선수가 없으면 메모만 지운다. 버프(라벨)는 만료까지 남지만 편집기의 "뺄 수 없음" 검사는 선발에 있을 때만 걸리므로 막히는 조작은 없다.
  - 밀려난 선수(`fx-<pid>`)가 방출·트레이드·2군: 되돌리지 않고 끝난다 (고정 선수가 그 칸에 남는다).
  - 남는 어긋남 ①: 밀려난 선수가 만료 시점에 부상 중이어도 선발 칸에 돌아온다 (경기 때는 벤치가 대신 나서고, 나으면 그대로 주전).
  - 남는 어긋남 ②: 고정 선수가 부상자 명단에 다녀오는 사이 다른 선수 Z 가 그 칸을 메웠다면, 복귀 뒤 다시 들어가며 Z 를 밀어내지만 메모에는 처음 밀려난 선수만 있어 만료 때 Z 는 벤치에 남을 수 있다.
  - 남는 어긋남 ③: 같은 포지션의 고정 선수가 둘이면(베테랑 카드 + 2군 폭격 카드) 경기마다 서로를 밀어낸다. 재현하지 않았다(추정).
- (a) 의 남은 변형: 대체 선수 X 가 다쳤을 때 카드에서 **"감독에게 맡긴다"**를 골랐고 X 가 부상자 명단으로 가면(10경기 이상), X 의 표시가 지워지면서 원래 주인 A 와의 연결이 끊긴다. 이때 그 칸은 감독(fixLineup·자동 콜업)이 고른 선수가 맡고 있어 누구에게서 돌려받을지 기록이 없다 → A 는 나은 뒤 벤치에 남을 수 있다. **남김** — 칸 메모만으로는 되돌릴 대상을 알 수 없어 자동 처리 쪽에 기록을 추가해야 한다.
- 매각 카드·트레이드 카드는 선수 id 를 카드 id 에 실어 두므로 접어 둔 사이 선수단이 바뀌어도 다른 선수가 팔리지 않는다 (없어졌으면 "없던 일"). 부상 대체 카드만 순번으로 집고 있었다 → 10번.
- 스토어의 `substitute`·`swapLineup`·`swapPos`·`swapPitchers` 는 화면에서 부르는 곳이 없다(편집기는 `restoreLineup`·`callUpInto` 만 쓴다). 2군·부상 선수 검사가 없지만 닿지 않으므로 그대로 둔다.
- 포스트시즌 관중석 수는 `SEAT_LV.cap × 버프`로 계산하고 정규시즌은 `capacityOf(core)` 를 쓴다. 의도(밸런스)인지 알 수 없어 건드리지 않았다.

- 같은 종류(카드에 타순 순번을 굽는 곳) — **남김**:
  - 0장 `veteran` 카드(`events.ts` resolve 의 `t.lineup[Number(parts(cd)[1])]`): 카드를 접어 두고 타순을 바꾸면 베테랑이 카드에 적힌 선수가 아니라 그 순번에 지금 있는 선수 자리에 들어간다. 0장 한 번뿐인 카드라 낮음.
  - 주간 브리핑의 유망주 기용 제안(`briefing.ts` runOffer `a.slot`): 브리핑을 연 채 오더 편집기로 타순을 바꾸면 같은 일이 생길 수 있다. **추정** — 이적·조치·카드 처리 뒤에는 `refreshBriefing` 으로 다시 만들지만 편집기(`restoreLineup`) 뒤에는 부르지 않는다. 재현하지 않았다.
