# 10구단 체제 (1단계 — 게임 엔진)

> 작업 중인 초안. 단계가 끝날 때마다 갱신한다.

## 결정 사항

1. **구단 수는 세이브에서 읽는다.** 구단 수 = `core.teams.length`, 시즌 경기 수 = `core.schedule.length`.
   기존 8구단 세이브는 8구단·84경기로 그대로 이어지고, 새 게임만 10구단·81경기다. `store.ts` migrate 는 구단을 추가하지 않는다.
2. **10구단 시즌 = 81경기**: 상대 9팀 × 3연전 × 3바퀴. 바퀴 수는 "84경기에 가장 가까운 바퀴 수"로 구단 수에서 유도한다(8팀 → 4바퀴 84경기).
3. **유저 구단은 홈 3연전 14번(홈 42 · 원정 39)** 이 되게 일정을 짠다. 나머지는 13/14 혼합. 상대별 홈/원정 5:4 또는 4:5.
4. **새 구단 2개**(수원, 창원) — 가상 구단, tier 56~58 로 리그 전력의 가운데~아래.
5. **포스트시즌**: 8구단은 4팀(준PO 3전2승 → PO 5전3승 → KS 7전4승) 그대로.
   10구단은 5팀: 와일드카드 결정전(4위 vs 5위, 전부 4위 홈, 4위 1승 선취, 최대 2경기)을 맨 앞에 추가.
6. **"n경기째" 상수는 84 기준 비율로 환산**: `dayAt(core, 72)` = round(72 × 시즌경기수 / 84). 8구단에서는 값이 그대로다.
7. **시즌 합계 기준 돈은 경기 수로 나눈다**(연봉·유지비·이자·분배금). 홈경기 수입은 그대로.
8. **리그 규모 비례**: FA·드래프트·AI 스토브리그·트레이드 탐색·타이틀·꼴찌 판정이 구단 수를 읽는다.
   헬퍼: `leagueSize(core)`, `seasonGames(core)`, `dayAt(core, d)`, `postTeams(core)`, `isLast(core, rank)`.
9. 점검용 8구단 코어: `newCore(seed, { teams: 8 })`.
