# KBL 레벨디자인 명세 v2 — 캠페인 「제주의 기적」

상위 문서: `LEVEL_CONCEPT.md` (정의·원칙·보이는 것/숨기는 것). 충돌하면 개념 문서가 이긴다.
타입 계약: `src/game/types.ts` — **오케스트레이터만 수정**. 튜닝 숫자는 `src/game/campaign.ts` 상단 테이블에 모은다. 아래 숫자는 초기값이며 봇 검증(8절)으로 조정한다.

## 1. 진행 단계 (Phase)

```
season(84경기) ─┬─ 유저 4위 이내 → post(유저 시리즈를 한 경기씩) ─┐
                └─ 5위 이하 → 포스트시즌 자동 시뮬 ───────────────┴→ ended(결산) → draft(신인 드래프트) → season …
                                                       신임 0 이하 → over(해임)
```

## 2. 스테이지 = 한 동사

메인 목표(깃발)는 **주제 동사를 한 번 제대로 쓰면 닿는 높이**, 별 3개는 고수용. 별은 추첨이 아니라 스테이지마다 고정이다.

| # | 이름 | 주제 동사(숨김) | 깃발 | 별 ★1 / ★2 / ★3 | 클리어 보상 |
|---|---|---|---|---|---|
| 0 | 구장을 채워라 | 가격·관중석 | 홈 평균 관중 6,200 | 매진 15회 / 장마 주간 평균 5,000 / 영업 흑자 10억 | 8억, 신임 +15 |
| 1 | 이기는 팀 | 영입·연봉 | 정규시즌 5위 이내 | 연봉 총액 40억 이하로 달성 / 주전 9명 중 OVR 60 미만 없음 / 팬 9,000 | 12억, +15 |
| 2 | 가을야구 | 육성·지명 | 포스트시즌 진출 | 25세 이하 주전(타순 or 선발) 3명 / 시즌 중 훈련 성장 25회 / 드래프트 출신 1군 기록 | 20억, +15 |
| 3 | 한국시리즈로 | 투수 운용 | 한국시리즈 진출 | 팀 ERA 리그 2위 이내 / 20세이브 마무리 / 포스트시즌 연투 패전 0 | 30억, +15 |
| 4 | 제주의 기적 | 전부 | 한국시리즈 우승 | 정규시즌 1위 / 평균 관중 16,000 / 무차입 | 50억, +20, 엔딩 |
| 5 | 왕조 (무한) | — | 포스트시즌 진출 | 우승 / 영업 흑자 30억 / 평균 관중 20,000 | 15억, +10 |

- 별 보상: 각 현금 1.5억~4억(스테이지 비례), 신임 +5. 획득한 별은 `campaign.achievements` 에 `"s<stage>-<n>"` 로 영구 기록(스테이지를 넘긴 뒤에는 다시 딸 수 없다 — 그 레벨의 것).
- 깃발 실패: 신임 −20 (스테이지 0 은 −15). 시작 60, 상한 100. 같은 스테이지를 다시 한다.
- 월반: 결산 때 다음 스테이지의 깃발 조건도 이미 충족이면 연속 승급(최대 +2).
- 우승 시 `ending = true`, `titles++`, 스테이지 5.

## 3. 시즌 대본 (배치)

일정은 더 이상 완전 무작위가 아니다. 시즌마다 `campaign.beats` 에 구간을 깔고, 일정·날씨·수요·사건이 그 구간을 따른다.

| 구간 | 경기일 | 공통 |
|---|---|---|
| 기 | 0~11 | 주제 동사가 필요한 상황을 **안전하게** 한 번 겪는다 |
| 승 | 12~41 | 같은 상황이 더 큰 판돈으로 반복된다 |
| 중간 점검 | 42 직후 | 구단주 면담 카드(6절) |
| 전 | 48~59 | 주제를 뒤집는 구간. 일정표에 세계 안의 예보로 미리 보인다 |
| 결 | 72~83 | 마지막 시험. 일정이 이 구간에 맞춰 짜인다 |

스테이지별 배치:

| # | 기 | 승 | 전 | 결 |
|---|---|---|---|---|
| 0 | 개막 홈 3연전 "개막 특수"(수요 ×1.5) → 매진, 발길 돌린 팬 | 주말·인기 구단 홈경기 수요 초과 반복 | **장마 주간**: 비 확률 60%. 지붕 없는 구장은 수요 ×0.6, 지붕(관중석 Lv3+) 있으면 ×0.85. 비싼 표일수록 더 빠진다 | 마지막 6경기 전부 홈 |
| 1 | 12일째 스카우트 도착: 저가 준척 FA 3명이 우리 팀 최약 포지션에 맞춰 시장에 나온다 | 스타 FA 가 시장에 등장(연봉이 흑자를 먹는다) | **부상 주간**: 주전 중 OVR 최고 타자·1선발이 8~12경기 결장. 벤치가 얇으면 무너진다 | 5·6위 팀과의 6연전 |
| 2 | 지난 드래프트 신인이 훈련 성과를 낸다(첫 2주 성장 확정 1회) | FA 시장이 마른다(가뭄: 스타 0, 준척 가격 +30%) | **세대교체**: 33세 이상 주전 2명이 능력치 급락. 대체할 젊은 선수가 있는가 | 4·5위 팀과의 6연전 |
| 3 | 3연투 금지 규칙 공개: 연투한 불펜은 구위 −(연투 피로) | 주 6연전에 선발 5명 → 6번째 날 누굴 쓰는가 | **에이스 이탈**: 1선발 10경기 결장 | 1·2위 팀과의 6연전, 이후 포스트시즌 |
| 4 | — | 위 네 "전"이 약하게 전부 온다(장마 6경기, 부상 1명, 노쇠 1명) | **견제**: 상위 3팀이 유저전에 1~2선발을 맞춘다 | 한국시리즈 |

- 구현: `buildBeats(stage, rng): Beat[]`, 일정 생성은 `buildSchedule` 을 감싸 결 구간 조건(홈 6연전, 특정 순위대 팀)을 만족하도록 재배열. 결 구간의 "5·6위 팀"은 60경기 시점 순위로 확정해 남은 일정을 교환한다.
- 연투 피로(스테이지 3 의 동사): 전 시즌·전 스테이지에 적용되는 정식 규칙이다. 전날 던진 불펜 −4 구위, 2일 연속이면 −9. 투수 탭에 피로 표시. 스테이지 3 이전에는 영향이 작아 몰라도 되지만, 스테이지 3 의 배치가 그것을 드러낸다.
- 비 × 지붕, 비 × 매점(−20%, 실내 푸드홀 Lv5 는 감소 없음), 스타 × 굿즈 × 좌석처럼 **규칙의 곱**으로 상황을 만든다. 단발 보너스는 추가하지 않는다.

## 4. 동사 개방 (첫 시즌만)

1일 차에 탭을 전부 주지 않는다. `campaign.unlocked` 에 열린 동사를 기록하고, 닫힌 탭은 자물쇠 실루엣으로만 보인다. 열릴 때 구단주가 한마디 한다(설명문 금지, 상황 + 대사).

| 시점 | 열리는 동사 | 그 순간의 상황 | 구단주 한마디 |
|---|---|---|---|
| 시작 | 타순·투수 | — | "일단 오늘 경기부터 보세." |
| 1경기(홈 개막) 후 | 티켓 가격 | 매진, 발길 돌린 팬 | "표가 없어 돌아간 팬이 있다더군." |
| 첫 홈 3연전 후 | 관중석 증축 | 3경기 연속 매진 | "자리가 모자라면 늘리면 되지 않나?" |
| 첫 주말 홈경기 후 | 매점 | 매점 앞 긴 줄(구장에 보임) | "어묵 하나 사는 데 두 이닝이 지나갔다네." |
| 12경기 후 | 영입(FA) | 최약 포지션 타율 표시 | "스카우트가 명단을 들고 왔네." |
| 18경기 후 | 훈련장 | 공터에서 훈련하는 선수들 | "젊은 애들이 공터에서 캐치볼을 하더군." |
| 현금이 처음으로 사고 싶은 것보다 모자랄 때 (늦어도 30경기) | 대출 | — | "은행 지점장이 명함을 두고 갔네." |

- 첫 만남은 안전하게: 가격은 무료·가역이라 첫 동사다. 첫 증축은 개막 특수로 회수가 빠르다. 첫 FA 3명은 저가다.
- 우승 엔딩을 본 뒤의 새 게임, 또는 설정의 "전부 열기"는 개방 절차를 건너뛴다. 2시즌부터는 전부 열려 있다.
- 잠금은 로직에서도 검사한다(`isUnlocked(core, verb)`; 잠긴 액션은 error).

## 5. 사건은 생긴다 (이벤트 카드)

무작위 덱을 버린다. 카드마다 `when(core)` 조건과 우선순위가 있고, 매 경기 후 조건을 검사해 가장 우선순위 높은 1장을 낸다. 카드 간 최소 8경기 간격, 시즌 최대 5장(+ 중간 점검 1장). 모든 선택지는 트레이드오프가 있다.

| 카드 | 생기는 조건 | 선택 |
|---|---|---|
| 암표 소동 | 최근 홈 5경기 중 4매진 | 단속(비용, 만족도↑) / 방치(만족도↓) / 가격 인상 안내 |
| 팬 간담회 | 5연패 | 사과+할인 / 침묵 |
| 굿즈 콜라보 | 4연승 + star 70+ 보유 | 투자(굿즈 ×1.5, 12경기) / 패스 |
| 간판스타 연봉 요구 | star 최고 선수가 리그 타이틀 3위 이내 | 인상(+20%) / 거절(star↓, 팬↓) |
| 트레이드 제안 | 벤치에 OVR 65+ 가 있고 최약 포지션이 55 미만 | 수락 / 거절 |
| 조기 복귀 | 주전 부상 5경기 이상 남음 | 강행(재부상 30%) / 대기 |
| 은퇴 투어 | 35세 이상 star 60+ 보유, 60경기 이후 | 기념 경기(수요↑, 고정 출전) / 조용히 |
| 야시장 | 매점 Lv2+ 이고 평균 점유율 90%+ | 개장(매점 +25%, 유지비↑) / 거절 |
| 방송 다큐 | 순위 3계단 이상 상승 | 수락(팬↑, 집중력↓) / 거절 |
| 구단주 호출 | 신임 40 이하 | 공약(달성 +15 / 실패 −10) / 버티기 |
| 외인 교체 | 외인 선수가 부진(OVR 대비 성적 하위) | 교체 영입(비용) / 신뢰 |
| 태풍 | 장마 주간 중 1회(스테이지 0, 4) | 긴급 보수 / 방치(수용 −15%, 6홈경기) |

- **중간 점검**(42경기 직후, 매 시즌): 깃발 진행률을 구단주가 평한다. 뒤처졌으면 선택: 긴급 지원금(스테이지별 2억~6억, 대신 실패 시 신임 추가 −5) / 지금대로. 앞서 있으면: 목표 상향 내기(별 1개 조건 강화, 성공 시 보상 2배) / 사양.
- 지속 효과는 `campaign.buffs`.

## 6. 포스트시즌

- 1~4위. 준플레이오프 3위 vs 4위(3전 2선승) → 플레이오프 2위 vs 승자(5전 3선승) → 한국시리즈 1위 vs 승자(7전 4선승).
- 홈: 상위 시드가 3전제 1·3, 5전제 1·2·5, 7전제 1·2·6·7차전. 무승부 없음. 정규시즌 기록은 오염시키지 않는다.
- 유저 시리즈는 한 경기씩(DayReport.post). 유저 홈 수입: 수요 ×1.25/1.4/1.6, 티켓 정산 ×1.5. 배당금: 진출 3억 / PO 6억 / 준우승 12억 / 우승 25억.

## 7. 신인 드래프트

- 풀 28명(19~22세). 대졸 즉전감(OVR↑ pot↓) vs 고졸 원석(OVR↓ pot↑). `scout` 등급은 pot 의 흐릿한 표시.
- 3라운드, 전년도 역순. 계약금 1.5억/8천만/4천만, 연봉 최저. 지명 선수 `rookie: true`.
- AI 구단은 스토브리그에 FA 1~2명 영입 + 최하위 선수 방출. 외국인 보유 한도 3명.

## 8. 화면 (보이는 것 / 숨기는 것은 개념 문서 6절)

- TopBar: "1장 · 구장을 채워라" + 깃발 진행 막대 + 별 3개(획득/미획득) + 신임 게이지. 탭하면 캠페인 시트(스테이지 지도: 지나온 장 / 현재 / 다음은 실루엣).
- 일정표(리그 탭): 다가오는 구간의 세계 안 예보("장마 예보", "원정 6연전", "라이벌 6연전"). 구간의 이름(기승전결)은 표시하지 않는다.
- 구장 디오라마에 먼저 드러난다: 게이트 밖 대기 줄(발길 돌린 팬), 비 오는 날 지붕 없는 스탠드의 우산·빈자리, 매점 줄, 공터 훈련. `StadiumScene` 에 필요한 입력은 오케스트레이터가 타입에 추가한다.
- 결산 화면: 깃발 달성 여부 → 별 → 신임 변화 → 다음 장 공개(이름이 실루엣에서 드러남).

## 9. 봇 검증 (`npm run campaign`)

| 봇 | 행동 | 기대 |
|---|---|---|
| passive | 아무것도 안 함 | 시즌 3~4 에 해임 |
| sensible | 스테이지의 주제 동사를 상식적으로 쓴다 | 스테이지당 평균 1.3~1.8시즌, 우승 = 시즌 7~10, 해임률 < 15% |
| greedy | 스타 FA 올인 + 대출 한도 | 스테이지 0~1 은 빠르나 2 에서 막힘(육성 없음), 해임률 30%+ |
| off-verb | 주제 동사만 빼고 다 한다 | 깃발 달성률이 sensible 의 절반 이하 — **주제 동사가 실제로 열쇠인지** 검증 |

별 획득률 목표: sensible ★ 평균 1.0~1.5개/스테이지, 3개 전부는 10% 미만.
