# KBL 레벨디자인 명세 v3 — 캠페인 「제주의 기적」

상위 문서: `LEVEL_CONCEPT.md` (정의·원칙·보이는 것/숨기는 것·스토리). 충돌하면 개념 문서가 이긴다.
타입 계약: `src/game/types.ts` — **오케스트레이터만 수정**. 튜닝 숫자는 `src/game/campaign.ts` 상단 테이블, 대사·문구는 `src/game/story.ts` 에 모은다. 아래 숫자는 초기값이며 봇 검증(11절)으로 조정한다.

## 0. 전제

제주 탠저린즈는 감귤 조합이 주인인 **도민 구단**이고 만년 꼴찌다. 낡은 6,000석 구장에 수십 년 전 단 한 번의 우승 깃발이 바랜 채 걸려 있다. 리그는 관중·성적 미달 구단의 **연고 이전 심사**를 시작했고, 육지의 한 도시가 신축 돔구장을 내걸고 팀을 데려가려 한다. 그 우승 멤버였고 은퇴 후 귤 농사를 짓던 유저가 조합의 부탁으로 단장이 된다.

- 신임(trust)의 화면상 이름은 **도민 지지**. 0 이하 → `phase 'over'` = 팀이 섬을 떠난다(연고 이전).
- 돈이 없는 이유는 악당이 아니라 주인이 농민이기 때문이다. 적대자는 없고, 유혹이 있다.
- 첫 뉴스: 부임 기사 + 지난 5시즌 순위("8-8-7-8-8"). 과거 기록은 `story.ts` 상수.
- 실존 구단·인물명 금지.

## 1. 진행 단계 (Phase)

```
season(84경기) ─┬─ 유저 4위 이내 → post(유저 시리즈를 한 경기씩) ─┐
                └─ 5위 이하 → 포스트시즌 자동 시뮬 ───────────────┴→ ended(결산) → draft(신인 드래프트) → season …
                                                    도민 지지 0 이하 → over(연고 이전)
```

## 2. 장(스테이지) = 한 동사 = 한 인물

깃발은 주제 동사를 한 번 제대로 쓰면 닿는 높이. 별 3개는 장마다 고정이며 고수용.

| # | 이름 | 동사(숨김) | 인물 | 깃발 | 별 ★1 / ★2 / ★3 | 보상 |
|---|---|---|---|---|---|---|
| 0 | 고장 난 팀 | 타순·영입 | 감독, 스카우트 팀장 | 정규시즌 7위 이내 | 승률 .450 / 주전 9명 중 OVR 58 미만 없음 / 연봉 총액 증가 5억 이내로 달성 | 8억, 지지 +15 |
| 1 | 돌아온 관중 | 가격·관중석·매점 | 마케팅 팀장 | 홈 평균 관중 7,000 | 매진 15회 / 장마 구간 평균 관중 5,500 / 영업 흑자 10억 | 12억, +15 |
| 2 | 가을야구 | 육성·지명 | 2군 코치 | 포스트시즌 진출 | 25세 이하 주전 3명 / 시즌 훈련 성장 25회 / 드래프트 출신 1군 100타석 or 30이닝 | 20억, +15 |
| 3 | 한국시리즈로 | 투수 운용 | 투수 코치, 에이스 | 한국시리즈 진출 | 팀 ERA 리그 2위 이내 / 20세이브 마무리 / 포스트시즌 연투 패전 0 | 30억, +15 |
| 4 | 제주의 기적 | 전부 | 육지 도시의 유치위원장 | 한국시리즈 우승 | 정규시즌 1위 / 평균 관중 16,000 / 무차입 | 50억, +20, 엔딩 |
| 5 | 왕조 (무한) | — | — | 포스트시즌 진출 | 우승 / 영업 흑자 30억 / 평균 관중 20,000 | 15억, +10 |

- 별 보상: 현금 1.5억~4억(장 비례), 지지 +5. `campaign.achievements` 에 `"s<stage>-<n>"`.
- 깃발 실패: 지지 −20 (0장은 −15). 시작 60, 상한 100. 같은 장을 다시 한다.
- 월반: 결산 때 다음 장의 깃발도 이미 충족이면 연속 승급(최대 +2).
- 깃발은 앞 장의 성과 위에서 닿도록 잡는다. 1장의 관중 7,000 은 0장에서 이기기 시작한 팀의 팬 증가를 전제로 한다(인위적 수요 부스트 금지).

## 3. 시즌 대본 (배치)

`campaign.beats` 에 구간을 깔고 일정·날씨·사건이 그 구간을 따른다. 구간 이름(기승전결)은 유저에게 보이지 않고, 세계 안의 예보("죽음의 원정 6연전", "장마 예보")로만 일정표에 보인다.

| 구간 | 경기일 | 역할 |
|---|---|---|
| 기 | 0~11 | 주제 동사가 필요한 상황을 안전하게 한 번 |
| 승 | 12~41 | 같은 상황, 더 큰 판돈 |
| 중간 점검 | 42 직후 | 조합장 면담 카드 |
| 전 | 48~59 | 주제를 뒤집는다. 그 장 인물과의 갈등이 터진다 |
| 결 | 72~83 | 마지막 시험. 일정이 여기에 맞춰 짜인다 |

| # | 기 | 승 | 전 | 결 |
|---|---|---|---|---|
| 0 | **고장 난 타순**(부임 첫 시즌만): 벤치로 밀린 주전급 3명, 수비 위치 뒤바뀜 3쌍, 최약 타자가 3·4번, 선발 3명이 불펜. 고치는 건 무료·가역. 첫 12경기는 하위권 두 구단과 치른다(고장 난 채 승률 약 .29, 고치면 약 .49) | 12일째 스카우트 팀장의 명단: 최약 포지션 후보 3명. 그가 고른 1명은 옛 명성만 높다(나이·하락세가 카드에 보인다) | **죽음의 원정 6연전**(1·2위 팀). 연패 중 감독이 베테랑 복귀를 요구 | 7·8위 팀과의 6연전(꼴찌 직접 대결) |
| 1 | 개막 홈 3연전: 0장에서 늘어난 팬으로 수요가 좌석에 닿기 시작한다 | 주말·인기 구단전 매진과 발길 돌린 팬이 반복 | **장마**: 비 확률 60%. 지붕 없으면 수요 ×0.6, 지붕(관중석 Lv3+) ×0.85. 비싼 표일수록 더 빠진다 | 마지막 6경기 전부 홈 |
| 2 | 지난 드래프트 신인이 첫 2주에 훈련 성과 1회 확정 | FA 가뭄: 스타 0, 준척 가격 +30% | **세대교체**: 33세 이상 주전 2명 능력치 급락. 2군 코치는 "아직 이르다"고 한다 | 4·5위 팀과의 6연전 |
| 3 | 연투 피로가 처음 드러나는 주 6연전 | 선발 5명으로 6연전: 6번째 날 누구를 쓰는가 | **에이스 이탈**: 1선발 10경기 결장 | 1·2위 팀과의 6연전 → 포스트시즌 |
| 4 | — | 앞의 네 "전"이 약하게 전부 온다 | **돔구장의 제안**: 유치위원장이 거액의 이전 지원금을 내민다 | 한국시리즈 |

정식 규칙으로 추가하는 것(특정 장의 속임수가 아니라 항상 적용):
- **감독의 편성**: 0장 클리어 전까지 유저 팀의 [자동 편성]은 "감독에게 맡기기"다. 감독은 나이·연봉(이름값)에 가중치를 둔다. 0장을 넘기면 감독이 승복해 최적 편성이 된다.
- **충성 팬**: 팬의 35%는 성적 계수와 무관하게 온다(져도 오는 팬). 팬 규모와 시즌 수에 따라 최대 50%까지 자란다.
- **개막 효과**: 매 시즌 첫 홈 3연전 수요 ×1.15.
- **비 × 지붕 × 매점**: 위 장마 계수, 비 오는 날 매점 −20%(푸드홀 Lv5 는 감소 없음).
- **수비 조직력**: 낯선 자리에 선 야수가 많으면(불일치 페널티 합이 기준 초과) 실책과 인플레이 안타가 늘어난다. 타선 탭의 전력 막대 '수비' 칸에 드러난다.
- **구원 투수의 선발 등판**: 구위·제구 −12.
- **개막 3연전**: 매 시즌 홈, 맑음.
- **연투 피로**: 전날 던진 불펜 구위 −4, 2일 연속 −9. 투수 탭에 표시.
- **섬 팀**: 원정은 전부 비행기다. 원정 6연전 뒤 첫 홈경기는 팀 컨디션 소폭 하락(일정표에 보인다).
- **일괄 진행의 정지**: `1주 진행`/`시즌 끝까지`는 이벤트 카드, 전·결 구간의 시작, 중간 점검, 주전 부상에서 멈춘다.

## 4. 잠금 없음

탭은 처음부터 전부 열려 있다. 대신:
- 관련 상황이 생긴 탭에 **숫자 배지**(`campaign.hints`). 예: 매진 후 구장 탭, 스카우트 명단 도착 후 영입 탭.
- 인물은 방법을 말하지 않고 **자기 사정**을 말한다. 예: 감독 "저 친구는 15년을 뛰었습니다. 4번에서 빼면 라커룸이 가만있지 않을 겁니다."
- 설명 팝업·화살표·반짝임 유도 금지. 예상 결과(예상 수요, 능력치 비교)는 조작하는 자리에서 항상 보인다.

## 5. 사건은 생긴다 (이벤트 카드)

카드마다 `when(core)` 조건·우선순위·인물이 있고, 매 경기 후 검사해 1장을 낸다. 카드 간 최소 8경기, 시즌 최대 5장(+ 중간 점검, + 그 장의 "전" 카드). 모든 선택지는 대가가 있다.

| 카드 | 인물 | 조건 | 선택 |
|---|---|---|---|
| 베테랑 복귀 요구 (0장 전) | 감독 | 원정 6연전 중 3연패 | 복귀(전력↓, 감독 신뢰↑) / 고수(팬 만족↓ 6경기, 이후 승복) |
| 옛날 눈 (0장 승) | 스카우트 팀장 | 그가 고른 선수를 안 뽑음 / 뽑았는데 부진 | 믿어 준다 / 데이터 분석원 채용(드래프트 등급 정확도↑, 비용, 팀장과 서먹) |
| 암표 소동 | 마케팅 팀장 | 최근 홈 5경기 중 4매진 | 단속 / 방치 / 가격 인상 |
| 팬 간담회 | 마케팅 팀장 | 5연패 | 사과+할인 / 침묵 |
| 굿즈 콜라보 | 마케팅 팀장 | 4연승 + star 70+ | 투자 / 패스 |
| 관광객 패키지 | 마케팅 팀장 | 주말 홈경기 점유율 80% 미만 | 여행사 제휴(관중↑, 객단가↓, 도민 팬 만족 소폭↓) / 거절 |
| 간판의 연봉 요구 | 선수 본인 | star 최고 선수가 타이틀 3위 이내 | 인상 / 거절 |
| 트레이드 제안 | 스카우트 팀장 | 벤치 OVR 65+ & 최약 포지션 55 미만 | 수락 / 거절 |
| 조기 복귀 | 2군 코치 | 주전 부상 5경기 이상 | 강행(재부상 30%) / 대기 |
| 아직 이릅니다 (2장 전) | 2군 코치 | 세대교체 구간에서 23세 이하를 주전으로 올림 | 밀어붙임(성장↑ or 슬럼프) / 내림 |
| 팔은 소모품이 아니다 (3장) | 투수 코치 | 불펜 3연투 발생 | 휴식 보장(다음 3경기 해당 투수 불가) / 강행(부상 위험↑) |
| 은퇴 투어 | 선수 본인 | 35세+ star 60+, 60경기 이후 | 기념 경기 / 조용히 |
| 태풍 결항 | — | 장마 구간 중 1회 | 원정 경기 연기(더블헤더로 불펜 소모) / 배편 강행(컨디션↓) |
| 돔구장의 제안 (4장 전) | 유치위원장 | 4장 48경기 | 거절(지지 +10) / 협상 테이블에 앉는다(현금 +20억, 지지 −25, 팬 만족↓) |

**중간 점검**(42경기 직후, 매 시즌, 조합장): 깃발 진행률 평가. 뒤처졌으면 조합원 특별 출자(장별 2억~6억, 실패 시 지지 추가 −5) / 지금대로. 앞섰으면 목표 상향 약속(성공 시 보상 2배) / 사양.

## 6. 인물과 대사 (`story.ts`)

| 인물 | 한 줄 |
|---|---|
| 감독 | 유저의 옛 동료. 베테랑을 믿는다 |
| 스카우트 팀장 | 30년 경력의 옛날 눈. 악의는 없고, 절반만 옳다 |
| 마케팅 팀장 | 육지에서 내려온 유일한 낙관주의자 |
| 2군 코치 | 지금 쓰면 망가지고, 안 쓰면 썩는다고 한다 |
| 투수 코치 | 팔은 소모품이 아니라고 한다 |
| 조합장 | 귤 농사를 짓는 구단주 대표. 돈은 없고 미안함은 많다 |
| 유치위원장 | 4장에만 나온다. 정중하고, 조건이 좋다 |
| 외야석의 오랜 팬 | 대사 없음. 뉴스 한 줄과 구장의 한 자리로만 |

- 각 인물: 이름(가명), 직함, 픽셀 초상 시드, 장별 대사 3~5줄.
- 등장 위치: 이벤트 카드, 결산 화면, 장 시작 한 줄. 그 외에는 나오지 않는다.
- 대사 규칙: 한 번에 2문장 이하. 방법 지시 금지. 숫자 금지(숫자는 UI 가 보여준다).

## 7. 연대기 (플레이가 쓰는 역사)

- **구단사**: `campaign.history` → "8-8-7-5-3-1" 순위열 + 시즌별 한 줄.
- **시즌 이름**: 결산 때 `nameSeason(record)` 가 자동 명명. 규칙 12개 이상(전반기 승률 ≫ 후반기 → "봄에만 강했던 해", 마지막 12경기 9승 이상 → "9월의 기적", 장마 구간 관중 급감 → "장마에 무너진 해", 첫 가을야구 → "처음 맞은 가을" …).
- **프랜차이즈 스타**: 팀에서 5시즌 이상 뛴 star 60+ 선수. 팬 효과 ×1.3, 방출·트레이드 시 팬 −, 만족도 −. 은퇴하면 **영구결번**(`campaign.retired`)이 구장에 걸린다.
- **응원 문화**: 팬 규모·만족도·시즌 수로 `cheerLv 0~3`. 관중석 풍경이 바뀐다(주황 물결 → 깃발 → 대형 현수막).
- **엔딩**: 우승 장면이 아니라, 바랜 깃발 옆에 두 번째 깃발이 걸린 구장. 4장에서 협상 테이블에 앉았다면 엔딩 문구가 달라진다.

## 8. 포스트시즌

- 1~4위. 준플레이오프 3위 vs 4위(3전 2선승) → 플레이오프 2위 vs 승자(5전 3선승) → 한국시리즈 1위 vs 승자(7전 4선승).
- 홈: 상위 시드가 3전제 1·3, 5전제 1·2·5, 7전제 1·2·6·7차전. 무승부 없음. 정규시즌 기록 오염 금지.
- 유저 시리즈는 한 경기씩. 홈 수입: 수요 ×1.25/1.4/1.6, 티켓 정산 ×1.5. 배당금 3억 / 6억 / 12억 / 25억.

## 10. 화면

- TopBar: "1장 · 고장 난 팀" + 깃발 진행 막대 + 별 3개 + 도민 지지 게이지. 탭하면 캠페인 시트(지나온 장 / 현재 / 다음은 실루엣, 구단사 순위열).

- 일정표: 다가오는 구간의 예보.

## 11. 봇 검증 (`npm run campaign`)

| 봇 | 행동 | 기대 |
|---|---|---|
| passive | 아무것도 안 함(감독에게 맡김) | 시즌 3~4 에 연고 이전 |
| sensible | 그 장의 주제 동사를 상식적으로 쓴다 | 장당 평균 1.3~1.8시즌, 우승 = 시즌 7~10, 실패율 < 15% |
| greedy | 스타 FA 올인 + 대출 한도 | 0~1장은 빠르나 2장에서 막힘, 실패율 30%+ |
| off-verb | 주제 동사만 빼고 다 한다 | 깃발 달성률이 sensible 의 절반 이하 — 주제 동사가 실제 열쇠인지 검증 |

별 획득: sensible 평균 1.0~1.5개/장, 3개 전부는 10% 미만.
