# KBL 레벨디자인 — 캠페인 「제주의 기적」

MVP 는 "84경기를 돌리고 숫자를 본다"에서 끝났다. 이 문서는 그 위에 **목표 → 압박 → 보상 → 다음 목표**의 구조를 얹는다.
타입 계약은 `src/game/types.ts` (Phase / Postseason / Campaign / Objective / EventCard / DraftState / SeasonVerdict). **types.ts 는 오케스트레이터만 수정**한다.

## 0. 설계 원칙

1. **한 시즌 = 한 레벨.** 시즌마다 구단주가 메인 목표 1개 + 보조 목표 2개를 준다. 목표는 TopBar/패널에 늘 보이고 진행 막대가 매 경기 움직인다.
2. **난이도 곡선은 경제가 만든다.** 인위적 잠금 대신 "돈이 모자라서 전부는 못 한다"가 선택을 강요한다. 스테이지 클리어 보상(구단주 지원금)이 다음 스테이지의 투자 여력이 된다.
3. **실패는 즉사가 아니라 신임 하락.** 신임(trust) 0 이면 해임. 보통 3시즌 연속 실패해야 해임된다.
4. **시즌 안에도 박자가 있다.** 12경기마다 의사결정 이벤트 카드, 6경기마다 훈련 성과, 시즌 끝에 포스트시즌 → 결산 → 드래프트.
5. 숫자는 전부 `campaign.ts` 상단 상수/데이터 테이블에 모아 둔다(오케스트레이터가 튜닝).

## 1. 진행 단계 (Phase)

```
season(84경기) ─┬─ 유저 4위 이내 → post(유저 시리즈를 한 경기씩) ─┐
                └─ 5위 이하 → 포스트시즌 전체 자동 시뮬 ───────────┴→ ended(결산) → draft(신인 드래프트) → season …
                                                       신임 0 이하 → over(해임)
```

## 2. 스테이지 (STAGES)

| # | 이름 | 메인 목표 | 보조 목표 풀 (시즌마다 2개 추첨) | 클리어 보상 |
|---|---|---|---|---|
| 0 | 꼴찌 탈출 | 정규시즌 7위 이내 | 평균 관중 5,500 / 시설 레벨 합 1 이상 / 영업 흑자 | 지원금 8억, 신임 +15 |
| 1 | 중위권 도약 | 5위 이내 | 팬 8,000 / 매진 12회 / 평균 관중 7,500 / 시설 합 3 | 12억, +15 |
| 2 | 가을야구 | 포스트시즌 진출(4위 이내) | 매진 18회 / 영업손익 +10억 / 팬 12,000 / star 80+ 보유 | 20억, +15 |
| 3 | 한국시리즈로 | 한국시리즈 진출 | 평균 관중 12,000 / 시설 합 7 / 팬 18,000 / 부채 0 | 30억, +15 |
| 4 | 제주의 기적 | 한국시리즈 우승 | 평균 관중 16,000 / 영업손익 +30억 / 시설 합 9 | 50억, +20, **엔딩** |
| 5 | 왕조 (무한) | 포스트시즌 진출 | 위 풀에서 난도 높은 것 | 15억, +10 |

- 보조 목표 보상: 각 현금 1.5억~4억(스테이지에 비례) 또는 팬 +300~800, 신임 +5.
- 메인 실패: 신임 −20 (스테이지 0 은 −15). 시작 신임 60, 상한 100.
- **월반**: 결산 시 다음 스테이지의 메인 조건도 이미 충족했다면 연속 승급(최대 +2, 보상은 통과한 스테이지 전부 지급).
- 스테이지는 내려가지 않는다. 우승(스테이지 4 클리어) 시 `campaign.ending = true`, `titles++`, 이후 스테이지 5 무한 모드.
- `progress` 는 매 `advanceDay` 끝에 갱신(순위·승수·평균 관중·매진·팬·시설·부채 등 현재 값). `state` 는 결산 때 확정하되, 시즌 중 이미 확정적으로 달성된 것(시설·star 보유 등)은 `done` 으로 먼저 표시해도 된다.

### 결산 (`concludeSeason`)

정규시즌(또는 유저의 포스트시즌)이 끝나 `phase = 'ended'` 가 되는 순간 한 번 실행:
목표 판정 → 보상 지급(현금·팬) → 신임 가감 → 스테이지 승급 → 업적 판정 → `history` 에 SeasonRecord push → `campaign.verdict` 기록 → 신임 ≤ 0 이면 `phase = 'over'`.
포스트시즌 배당금: 진출 3억 / PO 6억 / 준우승 12억 / 우승 25억 (ledger.league 에 합산).

## 3. 포스트시즌 (KBO 사다리식, 8구단 축소판)

- 1~4위 진출. **준플레이오프** 3위 vs 4위 (3전 2선승) → **플레이오프** 2위 vs 승자 (5전 3선승) → **한국시리즈** 1위 vs 승자 (7전 4선승).
- 홈: 상위 시드가 3전제 1·3차전, 5전제 1·2·5차전, 7전제 1·2·6·7차전.
- 연장 15회, 무승부 없음(동점이면 계속). 선수 **정규시즌 기록은 오염시키지 않는다**(시리즈 경기 전후로 bat/pit 스탯 스냅샷 복원). 부상은 반영.
- 유저가 뛰는 시리즈는 `advanceDay` 한 번에 한 경기(하이라이트 재생 포함, DayReport.post 채움). 유저와 무관한 시리즈는 즉시 자동 시뮬.
- 유저 홈경기 수입: 수요 ×1.25 / 1.4 / 1.6, 티켓가 ×1.5 (표시가와 별개로 정산만). 연봉은 정산하지 않음(정규시즌분으로 끝), 유지비는 정산.
- 유저 탈락/우승 시 남은 시리즈를 끝까지 시뮬하고 `phase = 'ended'`.

## 4. 이벤트 카드

- 정규시즌 day 9, 21, 33, 45, 57, 69 경기 **직후** 1장. `campaign.event` 가 있으면 `advanceDay` 는 에러(스토어가 막음). `resolveEvent(core, choiceIdx, rng)` 로 해소.
- 풀 16장 이상, 조건부 등장, 시즌 내 중복 금지. 모든 카드는 **뚜렷한 트레이드오프**(현금 ↔ 팬 ↔ 전력 ↔ 만족도 ↔ 신임)가 있고 "무조건 정답"이 없어야 한다. 금액은 스테이지/팬 규모에 비례 스케일.
- 필수 포함:
  1. 지역 스폰서 제안 — 외야 광고판: 현금 +2억 / 팬 친화 구장 유지(만족도 +4)
  2. 팬 감사 데이 — 비용 5천만 → 팬 +250·만족도 +5 / 거절
  3. 유망주 집중 캠프 — 비용 8천만 → 25세 이하 1명 능력치 +3~5 / 거절
  4. 간판스타 연봉 인상 요구 — 수락(연봉 +20%) / 거절(star·컨디션 하락, 팬 −200)
  5. 트레이드 제안 — AI 구단이 우리 선수 1명 ↔ 자기 선수 1명(+현금) 제시: 수락/거절
  6. 태풍 피해 — 긴급 보수 1.2억 / 방치(다음 6홈경기 수용 −15%)
  7. 방송국 다큐 — 수락(팬 +400, 다음 6경기 팀 집중력 −) / 거절
  8. 외인 교체 시장 — 5억에 OVR 78~84 외인 즉시 영입(외인 한도 내) / 패스
  9. 연패 중 팬 간담회(5연패 이상일 때) — 사과+할인(티켓 수입 −, 만족도 +8) / 침묵(만족도 −6)
  10. 연승 중 굿즈 콜라보(4연승 이상) — 투자 6천만 → 굿즈 ×1.5 (12경기) / 패스
  11. 베테랑 은퇴 투어(35세 이상 보유) — 기념 경기(관중 수요 +20% 6홈경기, 그 선수 고정 출전) / 조용히
  12. 구단주 호출(신임 40 이하) — 공약 걸기(남은 시즌 승률 목표 달성 시 신임 +15, 실패 −10) / 버티기
  13. 지역 유소년 야구 후원 — 비용 4천만 → 다음 드래프트 풀 품질↑ + 팬 +150 / 거절
  14. 부상 선수 조기 복귀(부상자 있을 때) — 강행(즉시 복귀, 재부상 30%) / 대기
  15. 주차장 야시장 — 매점 수입 +25% (12홈경기), 만족도 +2, 유지비 소폭↑ / 거절
  16. 라이벌전 특별 프로모션 — 다음 홈 3연전 티켓 반값(관중·팬↑ 수입↓) / 정상가
- "N경기 동안 지속" 효과는 `campaign.buffs: Buff[]` 로 표현한다(kind 해석은 `campaign.ts` 소유, 시즌이 바뀌면 비움). 활성 버프는 UI 에 칩으로 보인다.

## 5. 신인 드래프트 (스토브리그)

- `beginDraft(core, rng)`: phase 'ended' → 'draft'. 풀 28명(19~22세, OVR 42~62, pot 55~90, `scout` 등급은 pot 에 ±노이즈를 준 흐릿한 표시: A≥80, B≥70, C≥60, D). 대졸 즉전감(22세, OVR 높고 pot 낮음) vs 고졸 원석(19세, OVR 낮고 pot 높음)의 선택.
- 3라운드, 매 라운드 전년도 정규시즌 **역순**(꼴찌가 1순위). AI 는 (pot 추정 + OVR + 팀 필요 포지션) 점수로 지명.
- `draftPick(core, pid, rng)`: 유저 지명 → 다음 유저 차례 또는 종료까지 AI 자동 진행. `draftSkip` (패스, 로스터 가득일 때). 지명 선수는 `rookie: true`, 연봉 최저(3000), 계약금 = 라운드별 1.5억/8천만/4천만.
- `finishDraft` → `nextSeason`. AI 구단은 스토브리그에 남은 FA 중 상위 선수를 전력 tier 에 맞게 1~2명 영입하고 로스터 23명을 넘는 최하위 선수를 방출 → 리그가 정체되지 않게.
- 외국인 선수 보유 한도 **3명**(KBO 규정). `signPlayer` 에서 검사.

## 6. 업적 (20개 이상)

id / 이름 / 설명 / 조건. 예: 첫 승, 첫 매진, 5연승, 10연승, 첫 흑자 시즌, 만원 관중 10회, 3할 타자 배출, 20홈런 타자, 10승 투수, 20세이브, 신인왕 배출, 리그 MVP 배출, 가을야구 첫 진출, 한국시리즈 진출, 우승, 2연패, 팬 1만/2만/3만, 구장 풀업그레이드, 무차입 경영, 드래프트 출신 주전 3명 등.
달성 즉시 뉴스(good) + `achievements` 에 push. 판정은 `advanceDay` 끝과 `concludeSeason` 에서.

## 7. 목표 난이도 (봇 검증: `scripts/campaign.ts`, `npm run campaign`)

휴리스틱 봇 3종으로 10시즌 × 시드 12개를 돌려 표로 출력한다.

| 봇 | 행동 | 기대 |
|---|---|---|
| passive | 아무것도 안 함 | 시즌 3~4 에 해임 |
| sensible | 돈이 되면 싼 업그레이드부터, 약한 포지션에 준척 FA, 티켓가 적정가 유지, 이벤트는 무난한 쪽 | 스테이지 2(가을야구) 클리어 = 시즌 3~5, 우승 = 시즌 6~9, 해임률 < 15% |
| greedy | 스타 FA 올인 + 대출 한도까지 | 초반 빠르지만 부채·연봉 압박으로 30% 이상 강제 매각/해임 경험 |

출력: 봇별 스테이지 도달 시즌 분포, 해임률, 시즌별 평균 순위/현금/팬/관중석 레벨. 이 표를 보고 오케스트레이터가 상수를 튜닝한다.
