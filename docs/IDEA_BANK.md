# 아이디어 뱅크

아직 채택하지 않은 아이디어를 모아 두는 곳. 채택되면 `LEVEL_DESIGN.md` 로 옮긴다.
공통 기준(확정 원칙): 누르기 전에 결과가 숫자로 보이고, 한 번 탭으로 실행하고, 직후에 결과를 확인시킨다. 매 경기 숙제가 되면 실패다 — 기본값은 항상 "감독에게 맡기기".

## A. 다음 경기 맞춤 대응 (2026-10-13 시작)

출발점: 실제 야구에서 가장 흔한 맞춤 대응은 **상대 선발 공략**이다.

| # | 아이디어 | 유저가 하는 일 | 필요한 새 규칙 | 메모 |
|---|---|---|---|---|
| A1 | **게임플랜 카드** | 경기 전 3장 중 1장 선택: 초구 공략 / 기다리기 / 뛰는 야구 / 장타 노림 / 스몰볼 | 상대 선발 유형(제구형·파이어볼러·땅볼형·기교파)과 상성. 맞으면 +, 틀리면 − | 가위바위보 구조. 카드마다 "승리 확률 44 → 49%" 표시. **1순위 후보** |
| A2 | **플래툰 오더** | "좌완 상대 오더" 한 번 탭 | 투수 좌/우투, 타자 좌/우/양타. 반대 손 상대 시 보너스 | 선수 데이터에 손잡이 추가 필요. 영입·드래프트에서 "좌타 대타 요원"의 가치가 생긴다 |
| A3 | **선발 매치업** | 로테이션 순서 조정: 상대 에이스에 맞불 / 피하기 | 없음(지금 규칙으로 가능). 상대 예상 선발을 3경기 앞까지 공개 | "버리는 경기"를 고르는 맛 |
| A4 | **3연전 계획** | 시리즈 3경기 중 "잡는 경기" 1개 지정 | 지정 경기는 필승조 총동원(연투 피로↑), 나머지는 휴식 | 연투 피로 규칙이 처음으로 유저의 선택이 된다. 3장(투수 운용)의 "기"로 적합 |
| A5 | **스카우팅 리포트** | 주당 분석 포인트를 어느 상대에 쓸지 선택 | 분석 안 한 상대의 정보는 "?"로 가려짐. 데이터 분석원 채용 시 포인트↑ | 정보 자체가 자원. 이미 있는 분석원 채용과 연결 |
| A6 | **천적 관계** | 특정 투수에 강한 타자를 선발로 | 타자×투수 상대 전적을 기록하고 표본이 쌓이면 소폭 보정 | 플레이가 쓰는 이야기("이 투수만 만나면 치는 선수") |
| A7 | **수비 시프트** | 상대 중심 타자 1명 지정 견제 | 당겨치기 성향. 지정 타자 타율↓, 나머지 소폭↑ | 포스트시즌용 |
| A8 | **원정 구장 특성** | 구장에 맞는 오더 | 구장마다 넓이·펜스(장타↑/수비·주력↑) | 상대 구단에 개성이 생긴다 |
| A9 | **상대 불펜 상태** | 상대가 연투로 지쳤으면 "후반 승부" | 상대 불펜 피로 공개 | A1 의 카드 한 장으로 흡수 가능 |
| A10 | **날씨 대응** | 비 예보 시 "선취점 야구" | 강우 콜드(5회 이후 종료) | 장마 구간과 연결 |

배치 제안: 평소에는 감독이 알아서 하고, **결 구간(순위 직접 대결)과 포스트시즌**에서만 게임플랜이 뜬다. 처음 등장은 0장 결 구간의 꼴찌 직접 대결.
