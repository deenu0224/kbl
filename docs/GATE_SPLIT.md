## ⑥ 상대 구장 성장 — 바꾼 뒤 (유저 승인 A)

모델 (`src/game/gate.ts awayFacilities` — 원정 몫 계산과 원정 구장 그림이 같이 쓴다. 난수 없음, 세이브 필드 없음):

- 관중석 단계 = min(4 = 2층 스타디움, 개막 단계 + ⌊(시즌 − 1) × (0.5 + 인기) / 4⌋). 개막 단계는 예전 그대로 tier 에서(61+ → 24,000 · 58+ → 18,000 · 그 밖 13,000석). 매점·훈련 = 관중석 − 1
- 시즌별 상대 9구단 평균(1-based Lv): 1~3시즌 3.89 · 4시즌 4.00 · 5~8시즌 4.67 · 9시즌~ 5.00 (전부 24,000석)
- 점유율 × (개막 좌석 / 지금 좌석)^0.2 — 13,000 → 24,000석이면 ×0.88 (관중은 늘되 점유율은 내려간다. 상한 1 그대로)
- 표값 = 1.1만 × 적정가(지금 시설) / 적정가(개막 시설) — 1.19 → 1.31 비율(×1.10)까지
- 1시즌은 모든 계수가 1 → 1~3시즌 수치는 나누기 직후와 같다
- 경기당 원정 몫 어림(리그 중간 순위·요일 평균·팬 5천→2.9만): 1시즌 3,634만 → 5시즌 4,557만 → 9시즌 5,027만 → 12시즌 5,122만
- '지난 시즌 성적'은 상대 구단 기록이 세이브에 없어서 쓰지 않았다(쓰려면 Core 에 optional 필드가 필요)
